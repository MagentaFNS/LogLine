## О проекте

**LogLine** — это экосистема, которая объединяет всё, что нужно разработчику в одном приложени

### Зачем это нужно?

-  **Мессенджер для команд и комьюнити**
-  **Аналитика прогресса (коммиты, время в коде, обучение)**
-  **Поиск работы и вакансии для разработчиков**
-  **Социальные профили и комьюнити**
-  **Заметки, snippets, документация**
-  **GitHub-интеграция**
-  **Командные workspace**

## Быстрый старт

Вот как запустить LogLine за пару минут:

1. **Клонируй репозиторий**  
   ```bash
   git clone https://github.com/MagentaFNS/LogLine.git
2. **Перейди в папку проекта и запусти**
**Следуй инструкции по установке в разделе Установка.**

3. **Начни записывать свои отчёты**
**Ты увидишь свой первый график прогресса уже через 5 минут.**

## Установка LogLine
<details> <summary><strong>macOS / Linux</strong></summary>
<pre>
cd LogLine
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
</pre>
</details>
<details> <summary><strong>Windows (PowerShell)</strong></summary>
<pre>
cd LogLine
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
</pre>
</details>

## Стек

| Компонент | Технология |
|-----------|------------|
| Backend | Go + Gin + GORM |
| Database | PostgreSQL |
| Web | React + TypeScript + Vite + Tailwind |
| Desktop | Tauri + React |
| Mobile | React Native + Expo |
| Realtime | WebSocket (Gorilla) |
