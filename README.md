## О проекте

**DevJournal** — это дневник разработчика с аналитикой. Ты и твоя команда каждый день пишете короткий отчёт: *«Что изучил, что сломал, что починил»*.  
Бэкенд анализирует ваши записи и показывает прогресс: график коммитов, частоту ошибок, количество нового кода.

- **Присоединяйтесь к разговору** — общайтесь с нами и нашим сообществом в [Discord](https://discord.gg/6bMMJZxyGS).

## Установка DevJournal

<details>
<summary><strong>macOS / Linux</strong></summary>

```bash
git clone https://github.com/MagentaFNS/devjournal.git
cd devjournal
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
</details>

<details>
<summary><strong>Windows (PowerShell)</strong></summary>

```powershell
git clone https://github.com/MagentaFNS/devjournal.git
cd devjournal
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```
</details>
